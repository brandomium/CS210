# CS210
SNHU CS210 Projects and Files
-----------------------------------------------------------------------------------------

-Summarize the project and what problem it was solving
  The project included within this repository is a submission for the SNHU CS210 Programming Languages course. The project aimed to track the frequency of purchased items from a grocery store, "Corner Grocer," as part of a fictional internship with "Chada Tech." 
  
--------------------------------------------------------------------------------------

- What did you do particularly well?
  While writing the code for this project, I produced easily transferrable and readable code, which is particularly helpful when my code needs to be passed on to another programmer for further work and implementation.
  
--------------------------------------------------------------------------------------

- Where could you enhance your code? How could these implementations make your code more efficient, secure, and so on?
  I can enhance my code by increasing its capability to handle other input files, as it only handles input from a specific file name given for this project. In addition, I would add more methods for error handling that would reflect in the user interface, such as I/O failures. This would allow my program to be more robust and flexible. Furthermore, certain items, such as menu handling, can be separated from main.cpp to improve readability and sustainability.
  
--------------------------------------------------------------------------------------

- Which pieces of code did you find most challenging to write, and how did you overcome this? What tools and resources are you adding to your support network?
  One of the hurdles I faced when writing for this project was sustainability and readability. The simplest solution was to create separate files that handled specific tasks, such as tracker.h and tracker.cpp instead of cramming everything in main.cpp.
  In addition to using Microsoft VS and other IDEs' integrated debugging features to aid in my future programming projects, I will use online forums, such as StackOverflow, to help solve various issues.

-------------------------------------------------------------------------------------

- What skills from this project will be particularly transferrable to other projects or coursework?
  Considering I have spent a reasonable amount of time figuring out how to split the workload between different classes and files and get them to interact with one another, I will use that practice in other projects to maintain sustainable and readable code.
  
--------------------------------------------------------------------------------------

- How did you make this program maintainable, readable, and adaptable?
  As I have mentioned before, I split specific functions into two other files, which allows for faster resolution of other issues. Additionally, by allocating certain functions to their own files, another programmer or my future self can easily browse the code and quickly determine the best course of action for future use. In addition, concise comments are included throughout the code.
